# 卡片文案 · 第二版（去掉模板腔）

## 这一版改了什么

第一版的毛病是**每条都用同一套小标题填一遍**，读起来像表单，不像有人看过这东西后说的话。

新规则五条：

1. **结论放第一行，敢下判断**。`装` / `别装` / `看情况` / `只在 X 项目里装`，不写"建议根据情况评估"。
2. **只写能验的**。数字、原文引用、路径、命令。英文 description 不复述——那是搬运，不是介绍。
3. **段落长短随信息量走**。有的技能两行说完，有的值得六行。齐整是假的味道来源。
4. **可以带态度**。允许说"这个价格不值""涨得有点莫名其妙"。没有态度的评价没人信。
5. **不升华**。结尾不再加"这正是目录要标注废弃状态的理由"这种总结句，让事实自己收尾。

## prisma-postgres · 别装

362,998 次安装，正文 369 字，没有一条 setup 步骤。原文就一句：`This compatibility entry contains no setup recipes.`

它唯一的活儿是：老名字 `prisma-postgres` 还有人喊，就留个壳，把请求转到 `prisma-postgres-setup`。

要装的是这个：

```
npx skills add prisma/skills --skill prisma-postgres-setup
```

36 万人装了个空壳，八周还涨了 35%。安装量这个指标单独看是没救的。

## frontend-design · 优先装

Anthropic 自己写的，9077 字，通篇在解决一件事：怎么让模型做出来的界面不像 AI 做的。

它不让模型直接写代码。先把角色按上去——一个以"每个客户都有独特视觉识别"著称的工作室主创，客户已经否掉了所有套路方案。然后逼它先答清楚这个产品到底是什么、配色凭什么选这个配色，才准动 CSS。中间有一节是自我批判：对着 brief 找出自己在哪里回避了取舍。

100 万安装，八周翻了一倍（+105%），是这批里涨得最猛的。

局限：只给方法论，不给代码。不写前端的人装了没用。

## agent-browser · 装，但正文不在本地

Vercel 的浏览器自动化 CLI，CDP 驱 Chrome，靠无障碍树快照 + `@eN` 元素引用做点击，比截图+坐标那套稳。

装完别急着用。技能里的 `SKILL.md` 只是个发现桩，明确写着 `This file is a discovery stub, not the usage guide.`，真文档得从 CLI 里取：

```
npm i -g agent-browser && agent-browser install
agent-browser skills get core          # 加 --full 取完整命令参考
```

好处是文档永远跟安装的版本对齐；坏处是断网或 CLI 没装好时，这个技能等于空的——109 万人装了，其中不少大概卡在这一步。

## lark-drive · 用飞书的装，注意已经过峰

飞书云空间的操作手册，靠 `lark-cli` 管文件：上传下载、建目录、复制移动、权限评论、密级标签，也能把本地 Word/Markdown/Excel 导成 docx/sheet/bitable。

开头两条分流规则是这技能最值钱的地方，能省掉一堆误操作：

- 导 bitable 必须走 `lark-cli drive +import --type bitable`，别先切到 `lark-base`——那个只管导入完之后的表内操作。
- 复制在线文档必须走 `drive +copy`。别导出再导入，也别 fetch 正文重建。

两个前提：先读同仓库的 `../lark-shared/SKILL.md` 拿认证，另需飞书应用凭证。

46 万安装，但八周掉了 52%，是这 12 个里跌得最狠的。可能是飞书那边接口或 CLI 变了，可能是同类替代品分了流——上首页前值得查一下原因，别把正在退场的技能推给用户。
